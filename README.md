## About JadaDev Co

**JadaDev Co** is a software development identity behind projects that make technology more accessible, practical, and enjoyable. Our work spans developer infrastructure, online communities, file-sharing services, and gaming platforms.

We build with a focus on **usability, independence, and real-world problems** — from simplifying Windows web hosting to creating spaces where gaming communities can connect.

> **Build useful things. Keep improving them. Share what you learn.**

## Flagship Project — WeebX

<div align="center">

### [WeebX — Your Web Stack, Under Your Control](https://weebx.jadadev.com/)

**A Windows web hosting and development platform built for greater control over your environment.**

[![Website](https://img.shields.io/badge/Explore-WeebX-00ADEF?style=for-the-badge&logo=googlechrome&logoColor=white)](https://weebx.jadadev.com/)
[![Source](https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/JadaDev/WeebX)
[![License](https://img.shields.io/github/license/JadaDev/WeebX?style=for-the-badge)](https://github.com/JadaDev/WeebX/blob/main/LICENSE)

</div>

WeebX aims to provide a streamlined alternative to traditional local web stacks, with capabilities designed for both development and more advanced hosting workflows.

- Manage websites, web services, and databases from one interface.
- Work with multiple PHP versions and site-specific configurations.
- Simplify application setup and common hosting tasks.
- Move between development and production-oriented configurations.
- Explore and contribute to an open-source project.

**[Visit WeebX](https://weebx.jadadev.com/) · [Explore the repository](https://github.com/JadaDev/WeebX)**
